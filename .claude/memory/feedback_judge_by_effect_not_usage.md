When asked which skills, plugins or tools are worth keeping, rate them by
effectiveness, not by usage counts. User rejected a usage-count review on
2026-10-29: "don't rely on how often we use it, base it on how effective it is".

**Why:** a rarely used tool can be the right one for a rare job; a popular one
can still produce bad output.

**How to apply:** evidence = what happened after each run (user acted on it,
said "fix all"/"approve", or complained / asked again / interrupted), trial
notes in `community/`, and whether the skill's rules fit our work. Usage count
only as a side note. Related: [[feedback-community-first-research]].
