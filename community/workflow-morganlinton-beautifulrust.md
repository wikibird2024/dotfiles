# morganlinton/BeautifulRust

<https://github.com/morganlinton/BeautifulRust> · Markdown/Python · MIT · fit 🟡

Three skills plus a clippy config: `rust-best-practices` (loads when the
agent writes Rust), `rust-review` (findings cite the rule broken and show
the fix), `rust-port` (C/C++/Python → Rust, ports the tests first). Rules
drawn from the Google Rust style guide, the Rust API Guidelines, Effective
Rust, Rust Design Patterns and Microsoft's Rust guidelines.

## When we would use it

- Next time we write Rust (tools, probe-rs work). `rust-review` fits as a
  second check after `/ponytail-review`.
- `lints/` clippy config can go into a Rust repo on its own.
