# obra/superpowers

<https://github.com/obra/superpowers> · Shell/Markdown · MIT · fit 🟡

Skill pack and method for Claude Code: brainstorm → written plan → TDD →
subagent per task → review → verify before "done". Installed as a plugin
(`superpowers@claude-plugins-official`, disabled on our machine).

## When we would use it

- Borrow single ideas into our own skills: "verify before claiming done"
  gate, plan files, subagent per task with review between steps.

## Watch-outs

- Large and opinionated; it overlaps our global CLAUDE.md rules and
  `/project-status`. Turning it all on changes how every session behaves.
- Busy repo (348 open issues): changes often.
