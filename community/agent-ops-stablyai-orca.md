# stablyai/orca

<https://github.com/stablyai/orca> · TypeScript · MIT · fit 🟡

Desktop app that runs Codex, Claude Code, OpenCode or Pi side by side, each
in its own git worktree; fan one prompt to several agents and merge the
best result. Own terminals with splits, phone app to watch and steer agents.

## When we would use it

- Only if tmux + `claude --worktree` stop being enough. Same job as
  workmux and agent-of-empires, plus a GUI and phone app.

## Watch-outs

  fitting into it.
