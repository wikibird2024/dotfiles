# jakubkrehel/skills

<https://github.com/jakubkrehel/skills> · Markdown · MIT · fit 🟡

14 interface skills by a design engineer (Interfaces magazine): reviews for
accessibility, layout, typography, color, UI polish and interface copy, plus
user-invoked tools (`break` stress-tests a component, `state-machine` shows
every state, `variant`, `build-design` from Figma, `teardown` illustrations).

## When we would use it

- `better-colors`: contrast checks and palette/token naming. Fits our dark,
  high-contrast `theme` profiles and the screens of our C# tools.
- `better-accessibility` / `better-writing`: one pass on a PC tool's UI
  (focus order, labels, error text) before handing it out.

## Watch-outs

- Web-first (HTML/CSS/React). Rules carry over to Avalonia, the examples don't.
- Overlaps impeccable for web UI taste; pick one per project.
- Install is `npx skills add` or a plugin marketplace; take only the one skill
  we need, by hand.
- ⚪ Only the README and the `better-colors` file list were read (scout
  level 1, commit `592aedc`); no `/scout check` yet.
