# zathura

Config for [zathura](https://pwmt.org/projects/zathura/), the light PDF viewer
(Sioyek is the one for searching datasheets, see `niri/README.md`).

Stowed by `steps/04_stow.sh` (`stow -R -t ~ zathura`). → `~/.config/zathura/zathurarc`

Copies selections to the clipboard, Vim-style scrolling (`Ctrl+d/u` half page, `Ctrl+f/b` full page),
plus zoom and page keys. Under niri, zathura opens beside the current window at half width.
