# alacritty

Config for the [Alacritty](https://alacritty.org) terminal (backup terminal; kitty is the main one).

Stowed by `steps/04_stow.sh` (`stow -R -t ~ alacritty`). → `~/.config/alacritty/alacritty.toml`

- Font: JetBrains Mono Nerd Font 10.5, 10 px padding, live reload.
- Colors: fixed, in `colors.toml`: the xfce4-terminal palette on black, red cursor, with
  warm cream `#ebdbb2` text. The `theme` command does **not** change alacritty; edit `colors.toml` instead.
